# 本地多用户

Cerulia 默认启用本地多用户，开机先显示 `Login:`。新盘只有两个内置账户：管理员 `root` 和普通用户 `user`。默认都不设密码，输入账户名就能登录。已有账户和密码会保留。

## 登录和管理

- `users` 查看账户和 `[admin]` 标志。`whoami` 显示当前账户名。
- 管理员可执行 `admin alice on` 授予管理员权限，或用 `admin alice off` 撤销。管理员和 `root` 拥有同样的权限，但保留自己的用户名、UID 和主目录。不能撤销内置 `root` 的管理员标志。
- 管理员可执行 `useradd alice` 创建带密码的账户。账户名支持 1–16 位小写英文字母、数字或下划线，最多 16 个账户（含内置账户）。
- `logout` 回到登录界面；`su alice` 或 `login alice` 可直接切换，如果该账户有密码就需要验证。用 `passwd` 为当前账户设置或更改密码：15–64 个可打印 ASCII 字符（包括空格），输入不回显。按 Esc 取消。

普通账户可使用自己的 `/home/<用户名>` 和只读的 `/bin`、`/system`，不能访问其他账户的目录、账户库或原始磁盘命令。`cd` 回主目录。没数据盘或无法创建主目录时，仍可登录，会进入只读的 `/system`。普通账户的 `rm` 直接删除文件，不进管理员的回收站。

ext4 支持真实的文件属主和权限位。普通用户可用 `chmod` 更改自己文件的权限；`chown` 需要管理员。FAT 和 exFAT 没有 Unix 权限位，Cerulia 会隔离主目录，但不能在这些分区上使用 `chmod` 或 `chown`。

**无密码的管理员账户可被任何能操作本机控制台的人登录。** 在多人共用的机器上，先给 `root` 和其他管理员账户设密码；无密码的账户按 Enter 就能解除锁屏。

有程序仍在运行时，先让程序退出再注销、切换用户或输入账户密码。切换时会清除本地终端的屏幕、滚屏和命令历史；外部串口记录不会被清除。

## 桌面

运行 `desktop` 并打开左侧的开始菜单（GNOME 主题中是 Activities）。账户名下面有两个按钮：

- **Lock**：锁定当前桌面。输入当前账户的密码解锁，窗口和未保存的内容保留。
- **Switch User**：确认后结束当前桌面会话，在图形界面输入另一个账户的用户名和密码。切换前请保存文件，旧窗口和终端历史不会带给新账户。

键盘也能操作：`F10` 打开开始菜单，按 `L` 锁屏或按 `U` 切换用户。登录框按 Tab 换输入框，按 Enter 提交；在锁屏上按 Esc 只清空密码。有程序在后台运行时，请先退出程序。

普通用户可用文件管理器、记事本、终端、时钟及关于页面。其他应用目前只开放给管理员。改密或创建账户仍在文本控制台完成，可通过开始菜单的 **Back to Terminal** 返回。

## 磁盘和恢复

- **持久化账户、密码和管理员标志需要开机自动选中的可写 exFAT 数据卷**。没有这种数据卷时，仍可用内置账户登录，`admin` 改动仅在本次开机有效，不能保存新账户或密码。若需更换数据卷，请接好后重新启动，不要为启用账户而格式化已有资料。保存过账户库后，`format` 和 `setdrive` 不可用，以免覆盖或切走账户卷。
- 常用的构建、运行脚本保留已有的 `disk.vhd`；它是数据盘，存着用户和文件，不要为了更新系统镜像而删除它。
- 请用管理员备份 `/etc/accounts.db` 和 `/etc/multiuser.on`，并把备份安全地放到别处。磁盘保存的是带盐的 PBKDF2-HMAC-SHA256 密码验证值，不是明文密码。如果账户库缺失（但启用标记还在）或损坏，系统不会退回免密 shell；关机后从可信备份恢复库文件，再重启。
- 这是运行中的系统访问隔离，**不加密磁盘**。物理取盘、换卷、从其他系统启动，或控制虚拟机/调试串口的人不在这一保护范围内。
- 当前只有一个活动会话。尚不支持后台保留多个用户桌面或自动密码恢复。
