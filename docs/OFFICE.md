# 桌面文稿

登录普通账户 `user`，输入 `desktop`，在开始菜单选 **Notepad**（刚进桌面也可以直接按 N）。默认打开当前目录的 `NOTE.TXT`；若文件不存在，第一次保存时创建它。建议在自己的家目录里写。

| 要做什么 | 操作 |
| --- | --- |
| 写一份新文稿 | File → New，输入 `memo.txt` 并回车。写完按 F3 保存。 |
| 接着改已有文稿 | File → Open，输入文件名或路径并回车；或在 File Manager 里打开文件预览，按 E 编辑完整文件。 |
| 留一个副本 | File → Save as，输入尚不存在的文件名。之后 F3 保存到新文件，原件不变。 |
| 调整光标 | 单击正文，或用方向键、Home、End、Page Up、Page Down。Edit → Start / End 跳到整份文稿的开头或结尾。 |
| 偶尔补一个汉字 | F2，输入 Unicode 十六进制码再回车，例如 `4e2d` 得到“中”。Esc 取消输入。这不是拼音输入法。 |

记事本编辑 **UTF-8 纯文本，最多 32 KiB（按文件字节数计）**。长段落会随窗口折行，不会往文件里多写换行。原有的 LF、CRLF 和制表符保留；新插入的换行沿用文件中第一处换行的样式。汉字按内置字库显示，缺字显示方框。新建、另存为使用当前目录和 8.3 文件名（例如 `report01.txt`）。不支持 Word 排版、表格或 DOCX。

打开失败不会清掉当前文稿。换卷后普通保存会被拒绝；要转存请明确选择 Save as。未保存时点窗口的关闭按钮，Y 放弃修改，其余键返回编辑。关机、退出桌面或切换账户前请先按 F3，确认显示 **Saved**。
